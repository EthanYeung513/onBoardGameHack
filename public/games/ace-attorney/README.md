# Ace Attorney assets

Sprites, backgrounds and shout graphics from the Ace Attorney Wiki (aceattorney.fandom.com). They are Capcom's
artwork, used here for a non-commercial hackathon demo. Remove this folder before any public or commercial release:
the Dilemma game falls back to its own drawn characters when a sprite is missing.

The file list lives in `src/games/dilemma/ace-attorney.json`. Re-download with `npm run fetch:ace-attorney`
(add `-- --force` to overwrite).
